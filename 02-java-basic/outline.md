# Java 基础语法大纲

范围：面向对象编程之前的 Java 基础语法。以下按讲解顺序罗列知识点，不划分幻灯片页面。

## 1. 控制台输出与程序基本结构

- `System.out.println(...)`：输出文本、输出结果并换行、输出空行。
- 最小程序骨架：类声明、`public static void main(String[] args)` 入口、方法中的语句。
- 公共类名与源文件名的对应关系，大小写敏感。
- 编译与运行：`javac 文件名.java`、`java 类名`，源文件与字节码文件。
- 大括号、分号、换行和缩进的初步认识；代码块与作用域在控制流部分展开。
- 单行注释 `//` 与块注释 `/* ... */`。

## 2. 变量

- 以 `int` 为例介绍变量的类型、名称和值。
- 声明、初始化、读取与重新赋值。
- 赋值运算符 `=`：计算右侧表达式，将结果存入左侧变量。
- 局部变量必须先赋值再读取。
- 标识符、关键字、大小写敏感与变量命名习惯。
- 使用变量保存和复用计算结果。
- 使用 `println(age)` 输出变量的值。
- 初步区分 `println("age")` 与 `println(age)`，字符串部分正式展开。

## 3. 基本数据类型

- 类型的作用与基本类型分类。
- 八种基本类型：`byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean`。
- 整数类型的位数、取值范围和基本选择。
- 整数字面量、`L` 后缀、数字中的下划线。
- 十进制、二进制、八进制和十六进制的字面量写法。
- 浮点类型的位数、范围、有效数字与近似表示。
- 浮点字面量的默认类型、`F` 后缀与科学计数法。
- 浮点特殊值：正无穷、负无穷、`NaN`。
- `char` 与字符字面量，单引号与双引号的区别。
- 转义序列：`\n`、`\t`、`\r`、`\b`、`\"`、`\'`、`\\`。
- `boolean`、`true`、`false`；布尔值与数值类型的区别。

## 4. final 与运算符

### 4.1 final

- 使用局部 `final` 变量保存固定值。
- `final` 限制重新赋值。
- 常量命名习惯。

### 4.2 运算符与表达式

- 表达式、操作数与求值结果。
- 算术运算：`+`、`-`、`*`、`/`、`%`。
- 整数除法与浮点除法，整数除法向零截断。
- 求余运算与负数求余。
- 整数与浮点数除以零的不同结果。
- 复合赋值：`+=`、`-=`、`*=`、`/=`、`%=`。
- 自增、自减：`++`、`--`，前缀与后缀的区别。
- 比较运算：`==`、`!=`、`<`、`>`、`<=`、`>=`。
- 赋值 `=` 与相等判断 `==` 的区别。
- 布尔运算：`&&`、`||`、`!`。
- 短路求值。
- 条件表达式：`条件 ? 值1 : 值2`。
- 运算符优先级、结合性与括号；结合性与操作数求值顺序的区别。

## 5. 类型转换与精度损失

- 数值类型的自动转换及常见转换方向。
- 混合数值运算中的类型提升。
- `byte`、`short`、`char` 参与二元算术运算时提升为 `int`。
- 自动转换也可能损失精度，例如 `int` 转 `float`、`long` 转浮点类型。
- 强制类型转换的形式：`(目标类型) 表达式`。
- 浮点数转整数时的小数截断，以及截断与四舍五入的区别。
- 缩小整数类型范围时可能丢失信息。
- 转换发生的位置对结果的影响；赋值给 `double` 不会改变已经完成的整数除法。
- 复合赋值中隐含的类型转换。

## 6. 字符串基础

- `String` 与字符串字面量；`String` 不属于八种基本类型。
- 字符串变量的声明、初始化和赋值。
- `println("age")` 输出文字，`println(age)` 读取并输出变量的值。
- 字符与字符串的区别。
- 使用 `+` 拼接字符串，数值参与拼接时转换为文本。
- 字符串拼接与数值加法的区别，括号对结果的影响。

## 7. 函数（方法）

- Java 中的方法与函数的基本概念。
- 方法定义的形式：返回类型、方法名、参数列表、方法体。
- 示例方法统一放在类内，使用 `static`，不展开面向对象相关规则。
- 方法调用的形式与执行过程。
- 形参与实参，参数的类型、数量和顺序。
- 无参数方法与多个参数的方法。
- 返回值、`return`、`void` 与无返回值的方法。
- 接收返回值，将方法调用用于表达式。
- `return` 返回结果与 `println` 输出结果的区别。
- 方法内的局部变量与参数的作用范围。
- 基本类型参数的值传递；修改形参不会修改调用方的变量。
- 文档注释 `/** ... */` 与 Javadoc 的基本用途。

## 8. 使用点号调用方法与 String 常用方法

- `变量.方法名(参数)` 的调用形式；仅介绍使用方式，不展开成员方法的定义与对象模型。
- 长度与字符访问：`length()`、`charAt()`，从零开始的索引与有效范围。
- 子串：`substring(start, end)`、`substring(start)`，左闭右开区间。
- 拼接与重复：`String.join()`、`repeat()`；识别通过类型名调用的写法。
- 内容比较：`equals()`、`equalsIgnoreCase()`。
- 字符串的 `==` 与内容比较的区别，引用概念只作必要说明。
- `null`、空串与空白字符串；`isEmpty()`、`isBlank()`。
- 调用方法前检查 `null`，结合短路求值。
- 查找：`indexOf()`、`lastIndexOf()`，未找到时返回 `-1`。
- 前后缀判断：`startsWith()`、`endsWith()`。
- 顺序比较：`compareTo()`，返回值的正负与零。
- 替换：`replace()`。
- 大小写转换：`toLowerCase()`、`toUpperCase()`。
- 去除首尾空白：`trim()`、`strip()`。
- 接收字符串处理方法的返回值；调用这些处理方法不会自动更新原变量。

## 9. 控制流

### 9.1 语句、代码块与作用域

- 顺序执行。
- 分号与语句边界，大括号与代码块。
- 换行、缩进与语法边界的区别。
- 空语句；条件或循环括号后误加分号的影响。
- 块内局部变量的作用域。

### 9.2 if 语句

- `if`、`if–else`、`else if`。
- 条件必须是布尔表达式。
- 分支的执行顺序与嵌套。
- `if` 语句与条件表达式的区别。

### 9.3 while 语句

- 条件判断、循环体与状态更新。
- 先判断再执行，可能执行零次。
- 循环结束条件、死循环与边界。

### 9.4 for 语句

- 初始化、继续条件、更新表达式与循环体。
- `for` 的执行顺序。
- 普通 `for` 与计数型 `while` 的对应关系。
- 循环变量的作用域与循环边界。
- `break`：结束当前循环。
- `continue`：跳过本轮剩余操作；在 `for` 中仍会执行更新表达式。

### 9.5 switch 语句（简要）

- 根据同一个表达式的值选择分支。
- 传统冒号写法中的 `case`、`default`、`break`。
- 分支贯穿执行。

### 9.6 do–while 语句（简要）

- 先执行后判断，至少执行一次。
- 与 `while` 的区别。
- 结尾分号。

## 10. 数组

- 数组保存一组同类型数据。
- 数组变量的声明、创建与初始化。
- 指定长度创建数组与直接提供初始元素。
- 数组元素的默认值，与局部变量必须先赋值的规则区分。
- 从零开始的下标，元素的读取与修改。
- 数组的 `length`，与字符串 `length()` 的写法区别。
- 数组长度固定，有效下标范围与下标越界。
- 使用普通 `for` 遍历数组。
- 增强 `for` 的形式与使用；给遍历变量赋值不等于替换数组元素。
- 数组赋值共享同一数组，不自动复制元素。
- 数组作为方法参数：可以通过参数修改数组元素，重新赋值形参不会替换调用方的数组变量。
- 回看入口中的 `String[] args`：命令行参数数组。

## 范围约定

- 不包含 `Scanner`、`Math` 及其方法和常量。
- `StringBuilder` 留到面向对象之后。
- 类、`main` 和 `static` 仅作程序骨架及方法示例所需的说明；类字段、类常量、实例方法、构造方法、封装、继承与多态留到面向对象部分。
- 字符串以英文、数字和常见标点为例，不展开字符编码与内部实现。
- 不展开异常处理、集合、泛型、文件读写等后续主题。
